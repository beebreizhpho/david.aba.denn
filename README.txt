DAVID.ABA.DENN — PORTFOLIO V2

Décompressez le ZIP puis ouvrez index.html dans un navigateur.
La version 2 comprend navigation d'album, miniatures, transitions douces,
mode plein écran, flèches clavier et texture argentique.

Les trois photos actuellement fournies donnent une image par album.
Je n'ai pas inventé de photos supplémentaires : la structure est prête à
recevoir plusieurs images par album.

Pour ajouter une photo :
1. Copiez-la dans assets.
2. Dans index.html, cherchez const albums.
3. Ajoutez au tableau photos de l'album :
   {src:"assets/nom-photo.jpg",caption:"Lieu, date"}
